Interaction notes

Hover plays the video (or gif); mouse-out pauses and resets to the start. No drop shadow, no hover-triggered resize. The card markup gains one wrapper (.media-wrap or .phone-outline) so the video sits exactly in place. This same pattern is now live on the real site's Live-Chat project card.
